My Teaching Flow for a Topic: Dart Classes, Objects & Constructors

This page documents how I teach a new topic in my Zoom class, using the Week 4 Dart object-oriented programming lesson as the example. Depending on class time, these steps take place across one or two class sessions.

Week 4 · Fall 2026Introduction to Mobile Application (Dart / Flutter)Instructor: Prof. Dimpy GillTAP 1.2.3 · 1.2.1

“The main focus is not earning points — it is earning knowledge.” Students work without pressure, learn from detailed feedback, and try again.

Learning objectives

  • Define a class and create objects from it.
  • Store object data in fields and write methods to perform actions.
  • Use traditional methods, arrow methods and getters.
  • Initialize objects using standard, shorthand and named constructors.
  • Understand initializer lists, privacy and constructor errors.

The teaching flow

  1. Before class

    Materials shared in advance

    The lecture slides and an interactive tutorial on Dart classes and constructors were posted to Canvas before class, so students could preview the topic and return to it afterwards.
    • Slides: Dart Classes, Objects & Constructors (35 slides)
    • Tutorial: Dart OOP Concepts — written for students coming from C# or Java, with practice questions and a quick check
  2. In class · Zoom

    Concept explanation with slides

    I explained each concept using a consistent Concept → Code → Output → Explanation pattern: classes and objects, fields and methods, arrow methods and getters, standard and shorthand constructors, final fields and initializer lists, privacy with _, named constructors, and common constructor errors.
  3. In class · Zoom breakout rooms

    Formative quiz with two attempts and detailed feedback

    Students took a 30-question formative quiz right after the explanation, each in their own breakout room with their screen shared.
    • Two attempts. After each attempt, students see detailed feedback explaining the correct answer, so the second attempt becomes a learning step, not a guess.
    • Low pressure. Because the quiz comes immediately after the lecture, information may not be retained at once. I tell students I will reopen the quiz if they need another attempt to reach full understanding.
    • Live support. I move between breakout rooms at random, see each student’s screen, answer questions and explain concepts one-on-one, and keep track of everyone’s progress.
  4. Applied practice · next step in my flow

    Hands-on project

    In my usual teaching flow, students next apply the concepts in a small programming project. A sample practice project for this topic is shown below.

Sample practice project: Library Book Tracker

SAMPLE This practice project was prepared for this documentation to illustrate the applied-practice step for this topic. It is not the project used in the Week 4 class session.

Task

Create a Book class for a small library and test it in main().

RequirementConcept practised
Fields title, author and totalCopies that cannot change after creationFinal fields
A private field _available with a public getter availablePrivacy, getters
Constructor Book(this.title, this.author, this.totalCopies) that sets _available to totalCopiesShorthand constructor, initializer list
Named constructor Book.reference(title, author) for a single-copy bookNamed constructors
Methods checkOut() (returns false if none are left) and returnCopy()Methods that change object state
Getter isAvailable and arrow method summary()Getters vs. methods, arrow syntax
In main(), create two books (one with each constructor), check copies out and back in, and print the resultsCreating and using objects

Reference solution 
class Book {
  final String title;      // set once per object
  final String author;
  final int totalCopies;
  int _available;          // library-private field

  // Shorthand constructor + initializer list
  Book(this.title, this.author, this.totalCopies) : _available = totalCopies;

  // Named constructor: a single-copy reference book
  Book.reference(this.title, this.author) : totalCopies = 1, _available = 1;

  int get available => _available;          // getter (no parentheses)
  bool get isAvailable => _available > 0;

  bool checkOut() {                         // method that changes state
    if (_available == 0) return false;
    _available--;
    return true;
  }

  void returnCopy() {
    if (_available < totalCopies) _available++;
  }

  String summary() => '$title by $author: $_available of $totalCopies available';
}

void main() {
  var guide = Book('Dart Basics', 'A. Rivera', 3);
  var handbook = Book.reference('Flutter Handbook', 'K. Chen');

  print(guide.summary());      // Dart Basics by A. Rivera: 3 of 3 available
  guide.checkOut();
  guide.checkOut();
  print(guide.summary());      // Dart Basics by A. Rivera: 1 of 3 available

  print(handbook.checkOut());  // true
  print(handbook.checkOut());  // false (no copies left)
  print(handbook.isAvailable); // false
  handbook.returnCopy();
  print(handbook.available);   // 1
}
