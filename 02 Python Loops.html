1 What is a loop?

Imagine you want to say "Good morning!" five times. You could write five separate lines — but that is boring and slow. A loop lets you write the action once and tell Python how many times to repeat it.

Loops are one of the most useful tools in programming. You will use them constantly.

Real-life analogy: Think of a loop like a song on repeat. You press play once, and the music keeps going until you say stop.

Python has two main types of loops:

  • for loop — repeat a fixed number of times, or go through a list
  • while loop — keep repeating as long as something is true

2 The for loop

A for loop goes through a collection of items one by one and runs the same code for each item.

Basic structure:

for item in collection:
    print(item)    # indented code runs each time
for — the keyword that starts the loop
item — a variable that holds the current value each time around
collection — the list of things to loop through
indented code — the action to run for each item (always indented with 4 spaces or a tab)

Here is the simplest example — looping through a list of names:

•••
Example 1 — loop through a list
code
names = ["Alice", "Bob", "Carol"]

for name in names:
    print(name)
output
Alice Bob Carol
Remember: The code inside the loop must be indented (pushed in by 4 spaces). Python uses indentation to know what belongs inside the loop.

You can loop through numbers too:

•••
Example 2 — loop through a list of numbers
code
scores = [10, 20, 30]

for score in scores:
    print("Score:", score)
output
Score: 10 Score: 20 Score: 30

Quick check — what is the output of this loop?
for x in [1, 2, 3]: print(x)

3 Using range()

You do not always have a list ready. When you just want to repeat something a certain number of times, use range(). It generates a sequence of numbers for you.

Three ways to use range():

range(5)          # 0, 1, 2, 3, 4  (start at 0)
range(1, 6)       # 1, 2, 3, 4, 5  (start at 1)
range(0, 10, 2)   # 0, 2, 4, 6, 8  (count by 2)
range(stop) — starts at 0, stops before the number you give
range(start, stop) — starts at start, stops before stop
range(start, stop, step) — jumps by step each time
•••
Example 3 — count from 1 to 5
code
for i in range(1, 6):
    print(i)
output
1 2 3 4 5

4 The while loop

A while loop keeps running as long as a condition is true. You use it when you do not know in advance how many times to repeat.

Basic structure:

while condition:
    do something
    update the condition
while — the keyword that starts the loop
condition — something that is either True or False. Loop runs while it is True
update — you must change something inside the loop, otherwise it runs forever
•••
Example 4 — count to 3 with while
code
count = 1

while count <= 3:
    print(count)
    count = count + 1
output
1 2 3
Warning — infinite loops: If you forget to update the variable inside a while loop, it will run forever and freeze your program. Always make sure the condition can eventually become False.

5 break and continue

Two special keywords let you control what happens inside a loop:

•••
Example 5 — break: stop the loop early
code
for i in range(1, 6):
    if i == 3:
        break
    print(i)
output
1 2
break exits the loop completely when it is reached. The number 3 is never printed because the loop stops before print(i) runs.
•••
Example 6 — continue: skip one turn
code
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
output
1 2 4 5
continue skips the rest of the current turn and jumps to the next one. The number 3 is skipped, but the loop keeps going.

7 Summary

for loop

for item in collection:
    print(item)

Best when you know what to loop through.

range()

for i in range(1, 6):
    print(i)

Generates a number sequence for you.

while loop

count = 1
while count <= 5:
    count += 1

Best when repeating until a condition is met.

break & continue

break     # stop loop
continue  # skip turn

Control what happens inside a loop.
